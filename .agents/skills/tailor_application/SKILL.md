# Job Application Tailoring Skill

When the user triggers this skill by providing a job description or a link, follow this strict procedure:

1. **Analyze the JD:**
   - Extract the core requirements (tools, soft skills, specific metrics requested).
   - Identify the preferred application method (Email, WhatsApp, Google Form).
   - Identify the required language (Indonesian or English).

2. **The Pivot Strategy:**
   - Map the JD's requirements directly to Revaldo's Kantar experience (Data processing, 60% automation, Dashboards) and Bangkit experience (Cross-functional PM, 5-week MVP, ML).
   - If the JD asks for an unrelated skill (e.g., HR, Sales), pivot Revaldo's organizational and soft skills to match it.

3. **Draft the Application:**
   - Write a ready-to-send email or WhatsApp message.
   - Use the exact Subject Line formatting requested by the JD (if any).
   - Follow the "Sat Set" rule: Get straight to the point, use metrics, and avoid generic fluff.

4. **Format for the User:**
   - Output the final text cleanly in a markdown block so the user can easily copy and paste it.
   - Do NOT output generic placeholders like `[Your Name]`; always use "Revaldo Gemino Kantana Sagala".
